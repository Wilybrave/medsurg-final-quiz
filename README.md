# Med-Surg Final Quiz

Practice quiz: electrolyte imbalance signs & symptoms, crystalloids & colloids, mannitol, albumin. 98-question bank; each test draws a random set (25 / 50 / all), shuffles questions and choices, explains every choice after you check, and lets you retake only the misses.

**Live:** https://wilybrave.github.io/medsurg-final-quiz/

Questions live in `data/questions.js`. Study aid only. The book and the instructor win if anything differs.
